Base64 to Image

Paste a Base64 string and download the image

Paste your Base64 code

How to convert Base64 to an image

  1. Paste your Base64 string into the box. It can start with data:image/...;base64, or be the raw code only.
  2. Press Show image to see the picture.
  3. Press Download image to save it to your device.

Where do Base64 images come from?

Developers often find Base64 images inside HTML source code, CSS files, API responses, JSON data or email source. This tool turns that text back into a picture you can see and save.

If the image does not appear

Make sure you copied the whole string with nothing cut off at the end, and that there are no extra quotation marks around it. If your code has no data: prefix, the tool assumes it is a PNG; if it is actually a JPG or GIF, add the right prefix, for example data:image/jpeg;base64,, before the code.

Frequently asked questions

Do I need the data:image prefix?

No. If it is missing, the tool adds a PNG prefix automatically. Adding the correct prefix yourself helps for JPG, GIF and WebP images.

Is my Base64 data sent anywhere?

No. Decoding happens in your browser and nothing is uploaded.

Why does it say the string is invalid?

The text is usually incomplete or contains extra characters such as quotes, spaces or line breaks from copying.

Can I convert an image to Base64 too?

Yes, use our Image to Base64 tool.
