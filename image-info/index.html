How to check an image's details

  1. Upload the picture you want to check.
  2. The tool shows the file name, type, file size, width, height and other details in a table.
  3. Use the details to check whether the image meets the size rules of a website, form or app.

Why check image details?

Many websites and application forms have rules such as "JPG only, under 200 KB, at least 600 × 600 pixels". Image Info tells you in a second whether your picture meets them. If it does not, use the Resizer, Compressor or Converter to fix it.

Pixels, file size and aspect ratio

Dimensions (width × height in pixels) describe how much detail the image holds. File size (KB or MB) is how much storage it takes, which depends on dimensions, format and compression. Aspect ratio is the shape of the image, such as 16:9 for widescreen or 1:1 for a square.

Frequently asked questions

Does this tool show camera EXIF data?

No. It shows the main file details: name, type, size, dimensions and aspect ratio. It does not read camera settings or GPS location.

What is 1 MB in KB?

On this site, 1 MB is shown as 1,024 KB, and 1 KB is 1,024 bytes.

Is my image uploaded to check it?

No. Your browser reads the details on your device.

Which formats can I check?

Any image format your browser can open, including JPG, PNG, WebP, GIF, BMP and SVG.
