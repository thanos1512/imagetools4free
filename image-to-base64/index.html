How to convert an image to Base64

  1. Upload the image you want to encode.
  2. The tool creates the Base64 code straight away and shows the first part of it.
  3. Press Copy code to copy the full code, or Save as .txt to download it as a text file.

What is Base64?

Base64 is a way of writing binary data, such as a picture, using only ordinary letters, numbers and a few symbols. The result is a long piece of text that can be placed directly inside HTML, CSS, JSON or an email, without a separate image file.

This tool gives you a complete data URL, which starts with something like data:image/png;base64,. You can paste it directly where an image address is expected.

How to use the code

In HTML: <img src="data:image/png;base64,..." alt="logo">

In CSS: background-image: url("data:image/png;base64,...");

Base64 text is about 33% larger than the original file, so it is best for small images such as icons, small logos and email signatures. Large photos are better served as normal image files.

Frequently asked questions

Why is the Base64 code bigger than my image?

Base64 uses four characters to store every three bytes of data, so the text is roughly one third larger than the original file.

Can I turn the code back into an image?

Yes. Paste it into our Base64 to Image tool to preview and download the picture.

Is my image sent to a server to be encoded?

No. Your browser does the encoding on your device.

Which image formats are supported?

Any format your browser can open, including JPG, PNG, WebP, GIF, BMP and SVG.
