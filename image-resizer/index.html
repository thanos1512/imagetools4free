How to resize an image

  1. Upload your picture by clicking the upload box or dragging the file onto it.
  2. The current width and height appear in the boxes. Type the new width or height in pixels.
  3. Leave Keep proportions on so the other side changes automatically and the picture is not stretched.
  4. Press Resize and download. The resized image is saved as a PNG file named with its new size.

Keep proportions or not?

Every picture has an aspect ratio, which is the relationship between its width and height. When Keep proportions is on, changing one number updates the other so the ratio stays the same and nothing looks squashed. Turn it off only when you need an exact width and height and do not mind some stretching. If you need an exact shape without stretching, crop the image to that shape first, then resize it.

Making images bigger

You can enlarge an image, but the resizer cannot invent detail that was not in the original, so a big increase will look soft or blurry. For the sharpest results, start from the largest original you have and make it smaller rather than larger.

Frequently asked questions

Does resizing reduce file size?

Making an image smaller in pixels usually reduces the file size a lot. Because the resizer saves as PNG, run the result through the Image Compressor afterwards if you need a small JPG or WebP file.

Why is the resized file saved as PNG?

PNG keeps full quality and transparency, so nothing is lost during resizing. You can convert it to JPG or WebP with the Format Converter.

Can I resize photos from my phone?

Yes. The tool works in mobile browsers on Android and iPhone. Tap the upload box and choose a photo from your gallery.

Is there a maximum image size?

There is no fixed limit, but very large images (above about 8,000 pixels on a side) can be slow or fail on phones with little memory.
